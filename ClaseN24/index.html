🌐 DOM - Document Object Model

¿Qué es el DOM?

El Modelo de Objetos del Documento (DOM) es una representación estructurada de tu página HTML que JavaScript puede leer y modificar dinámicamente.

📚 Resumen de Conceptos

✅ DOM: Representación de objetos de tu HTML
✅ Nodos: Cada elemento HTML es un objeto
✅ document: Objeto global para acceder al DOM
✅ Selectores: Métodos para encontrar elementos
✅ innerHTML/innerText: Propiedades para modificar contenido
