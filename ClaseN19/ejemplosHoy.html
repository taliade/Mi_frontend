Arrays (Arreglos)

¿Qué es un Array?
Un Array es un objeto que almacena una lista de elementos. Puede contener números, strings, booleanos, objetos o incluso otros arrays.
let primerArray = ['Pokemon', 'Pikachu', 1.6, true]; // Índices: 0 1 2 3

Métodos de Arrays

.push() - Agregar al final

Agrega elementos al final del array

.pop() - Quitar del final

Elimina el último elemento

.shift() - Quitar del inicio

Elimina el primer elemento

.unshift() - Agregar al inicio

Agrega elementos al principio

.join() - Unir elementos

Une elementos con un separador

.indexOf() - Buscar elemento

Encuentra la posición de un elemento

Strings (Cadenas de texto)

Los strings son como arrays de caracteres
Cada carácter tiene un índice, empezando desde 0.
let saludo = 'Bienvenidas chicas!'; // 0123456789... console.log(saludo[5]); // 'e'

.length - Longitud

Cuenta caracteres (incluye espacios)

.indexOf() - Buscar texto

Encuentra posición de una palabra

.slice() - Cortar texto

Extrae una parte del string

.trim() - Quitar espacios

Elimina espacios al inicio y final

.split() - Dividir texto

Convierte string en array

.replace() - Reemplazar

Cambia una parte por otra
