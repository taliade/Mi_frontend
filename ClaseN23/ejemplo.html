📚 JSON y Web Storage

Aprende a manejar datos en el navegador con JavaScript

🔍 ¿Qué es JSON?

JSON (JavaScript Object Notation) es un formato de intercambio de datos ligero y fácil de leer. Aunque nació en JavaScript, es independiente del lenguaje y se usa ampliamente en desarrollo web.

Características principales:

  • 📝 Formato de texto plano
  • 🔄 Fácil de convertir entre string y objeto
  • 🌐 Estándar para APIs y comunicación web
  • 📊 Estructura de datos clave-valor

Métodos principales:

// Convertir objeto a JSON (string) JSON.stringify(objeto) // Convertir JSON (string) a objeto JSON.parse(jsonString)
💡 Importante: JSON solo acepta strings, números, booleanos, arrays, objetos y null. No acepta funciones, undefined, o fechas directamente.

💾 Web Storage API

La API de Web Storage permite guardar datos en el navegador del usuario sin necesidad de servidores.

🗃️ localStorage

  • Permanente: Persiste aunque cierres el navegador
  • Capacidad: 5-10 MB aprox.
  • Alcance: Compartido entre pestañas del mismo dominio

📋 sessionStorage

  • Temporal: Se borra al cerrar la pestaña
  • Capacidad: 5-10 MB aprox.
  • Alcance: Solo en la pestaña actual

Métodos principales:

// Guardar datos localStorage.setItem('clave', 'valor'); sessionStorage.setItem('clave', 'valor'); // Obtener datos localStorage.getItem('clave'); sessionStorage.getItem('clave'); // Eliminar datos localStorage.removeItem('clave'); localStorage.clear(); // Elimina todo
